# Lantern Wall v6 — 真砖重力井墙（设计定案）

> 定案日期：2026-07-26。取代 Living Blueprint v4.2 的「随滚方砖墙 + 邻域砖池翻板」
> 与中间迭代 v5「提灯砖墙」。本文是墙体系统的唯一正本；CLAUDE.md §2/§4/§6 的
> 墙体条款与本文交叉锁定。

## 1. 概念（第一性原理）

**墙 = 光前面的一排真砖；指针 = 压在墙上的重力井 + 墙后的一盏灯。**

- 砖是真的 DOM，缝隙就是真空隙——墙后的光（角落余晖 + 指针灯）**自己**从缝里
  透出，不存在任何假光/底衬/遮掩层
- 指针下压 = 重力井：近针的砖向墙内塌陷成碗，塌陷张开的缝与渐透的砖体透出
  墙后真灯光；离开即弹簧归位
- 墙属场景（fixed）：内容像图纸一样从墙前滚过，墙与光都不动——**零滚动耦合**
  （David 定案：墙不需要随内容滚动）

## 2. 单层砖纪律（v6 的核心不变量）

任何时刻**只有一层砖**：

| 路径 | 那一层砖 |
|---|---|
| 桌面精指针（hover+fine 且非 RM） | WallBricks 首次 pointermove 铺满视口的真砖 div 阵（零子元素） |
| 触屏 / reduced-motion / 无 JS / CSS var 解析失败 | 静态 SVG data-URI tile（`.bp-wall-face`，与真砖阵像素等价） |

- 切换机制：建砖同帧在 `.bp-wall` 落 `data-live` → tile `visibility: hidden`；
  RM 中途开启 teardown 时删属性复原。两者互斥存在，**永不叠加**
- ⚠️ 禁止回退到 v5 的「tile + DOM 砖 + 逐格底衬 + 假涌光」四层互相遮掩架构——
  那套机器存在的唯一理由是砖不是真的；单层真砖下一致性问题不复存在

## 3. 层结构（globals.css `.bp-wall*` 系）

```
.bp-wall            fixed inset-0, z -1, pointer-events none（属场景）
├─ .bp-wall-ambient 角落余晖：右上角径向微光 + 全场极低环境光（墙后，零 JS 恒在）
├─ .bp-wall-lamp    指针灯：560px 定尺寸径向圆，JS 只写 transform/opacity
│                   （纯合成零重绘；光心 α0.9 → 缝隙全量、砖面 10% 透射）
├─ .bp-wall-face    静态 tile ……………………………… z 1（[data-live] 时隐藏）
└─ .bp-wall-grid    真砖阵容器 …………………………… z 1（互斥显示，无层序问题）
```

- 砖 pitch：`--wall-brick-w` / `--wall-seam` 媒体查询阶梯——**56px 基准**
  （灯半径 200px ≈ 7 砖直径，单砖动作清晰可读）/ ≥2200px 64 / ≥3600px 96；
  缝恒 = pitch/16（tile viewBox 等比缩放保几何等价）；JS 只读不定
- 穿场光束方案已否决（与内容抢层级）；角落余晖是无指针路径的光源兜底

## 4. 重力井物理（WallBricks）

状态模型 = **全局仅 3 个标量弹簧**（井心 lx/ly + 强度 li，半隐式欧拉
k120 ζ≈0.82）；每块砖的响应都是井心位置的纯函数，零砖级状态：

| 动作 | 上限 | 说明 |
|---|---|---|
| 下陷 | DEPTH 16px（-z） | 坑心最深；perspective(600) 下自带 ~2.6% 透视缩 |
| 坡斜 | TILT 15° | 绕砖心沿碗壁坡度朝坑心倾（轴 = 径向向量垂线 `(uy,-ux)`）；无铰链、无背面问题 |
| 聚拢 | PULL 3px | 材料向坑心压聚（对向砖最坏合拢 ≈2.4px < 缝宽，不互叠） |
| 微缩 | SHRINK 0.05 | 坑内砖 scale 微缩——与透视缩合计压过聚拢，净效果 = 井内全部缝隙微张（坑心缝 ≈+0.6px）常亮透光、缝光随井深增强成光环（涌现行为，非手调） |
| 透光 | FADE 0.25 | 井深处砖面 opacity 渐降——墙后真灯光从砖体渗出 |

- 权重 `w = (1 - d/R)² · li`，R = 200；**中心阻尼** `min(1, d/faceSize)`
  作用于聚拢与坡斜（坑底方向不定 → 归零 = 碗底放平，免抖动）
- 强度弹簧是总开关：pointerleave 只把 ti 归零，位移/倾角/透光全部 ∝ li
  → 一根弹簧带全场归位
- 渲染：全砖扫描 + 平方距离预筛 + lastW 双零跳过（圈外砖零成本）；
  逐帧只写 transform / opacity；弹簧收敛即停帧；滚动时 JS 一行不跑
- per-element `perspective()` 内嵌 transform，不建 preserve-3d 链（与按钮
  系统同口径）

## 5. 哑光纪律豁免口径

指针灯 + 井心透光是全站哑光纪律的唯一窄豁免（mouse-tracking 豁免第 2 例）：
强度弹簧驱动、离开归零、光心 α≤0.9、砖面透光降幅 ≤0.25。角落余晖维持
氛围档（径向核 α0.3），不参与豁免。

## 6. 退役清单（v4.2 → v6）

- 逐砖弹簧 / 铰链解算 / Map 键控砖池 / acquire-release 回收 / z-index 升降
- 逐格不透明底衬 + 假涌光层（`.bp-brick-under` / `.bp-brick-uglow` /
  `.bp-brick-glow` / `.bp-brick-spill`）
- 文档级锚定 + 滚动重瞄 + 越界 overflow 裁切（墙 fixed 后滚动耦合整体消失）
- 缝隙灯槽层 `.bp-wall-light`、fixed 洗墙光 `.bp-wall-wash`、穿场光束（v5 中间态）
- 「静态层恒在 + 逐格接管」条款（v4.2）→ 单层砖互斥切换（v6）
